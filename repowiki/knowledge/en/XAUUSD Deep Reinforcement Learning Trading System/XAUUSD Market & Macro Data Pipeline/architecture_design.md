The module is split into two layers. The `data/` package holds reusable ingestion utilities (`load_data.load_ohlc_csv` normalizes MetaTrader `<DATE>/<TIME>` columns into a standard `time`+OHLCV schema and validates OHLC invariants) plus static assets: per-timeframe CSVs (`xauusd_m5`, `m15`, `h1`, `h4`, `d1`), a merged macro file (`xauusd_h1_macro.csv`), and a pre-generated economic calendar JSON (`economic_events_2015_2025.json`). `merge_macro.py` loads a master hourly XAUUSD series via `load_ohlc_csv`, then left-joins daily proxies (DXY, S&P 500, US 10Y) by forward-filling to the hourly index. `scripts/` contains one-shot ETL entry points: `fetch_all_data.py` downloads daily series (VIX, WTI, BTC, EURUSD, Silver, GLD, DXY) from Yahoo Finance via `yfinance` and writes them under `data/`; `resample_m1_to_all_timeframes.py` reads an M1 MT5 dump and produces M5/M15/H1/H4/D1 bars using pandas `resample` aggregations; `generate_economic_calendar.py` builds the USD event schedule (NFP, CPI, FOMC, GDP, Retail Sales, PCE) with date heuristics and serializes it to the JSON asset consumed at runtime. Dependency direction is strictly scripts → `data/` utilities; no cross-imports between sibling scripts.
