Run `python scripts/fetch_all_data.py` to download daily macro/market series into `data/` (auto-installs `yfinance` if missing); run `python scripts/resample_m1_to_all_timeframes.py` to derive M5/M15/H1/H4/D1 bars from an M1 MT5 dump placed at `data/XAUUSD_M1.csv`; run `python scripts/generate_economic_calendar.py` to regenerate `data/economic_events_2015_2025.json`; run `python data/merge_macro.py` to re-join daily proxies onto the hourly master.
