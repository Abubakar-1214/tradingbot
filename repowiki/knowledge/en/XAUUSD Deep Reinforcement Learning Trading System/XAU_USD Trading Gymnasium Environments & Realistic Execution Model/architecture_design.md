The module is organized as three sibling components under `env/`:
- `xauusd_env.py` defines `XAUUSDTradingEnv`, a discrete long-only gymnasium environment with action space {Flat=0, Long=1}, a rolling window observation of shape `(window * F + 1)` (flattened feature history plus current position), and a reward composed of PnL minus trade cost, turnover penalty, flat penalty, plus a hold bonus. Position is applied on the next step to prevent look-ahead.
- `xauusd_env_aggressive.py` defines `XAUUSDTradingEnvAggressive`, a variant with a wider 128-step window, a 3-way action space {Short=-1, Flat=0, Long=1} mapped via `action - 1`, leverage scaling, and a per-bar stop-loss that truncates the episode when hit.
- `realistic_execution.py` provides `RealisticExecutionModel` and `SlippageSimulator`, standalone classes that estimate total execution cost from a `market_state` dict (volatility, spread, liquidity, event flags) and adjust fill prices accordingly; they track cumulative statistics in a `cost_breakdown` dict.
Dependency direction is one-way: the two envs consume only numpy/gymnasium primitives; the execution model is independent and intended to be used by higher-level backtesters rather than being imported by the envs themselves. The package has no public API surface beyond the exported classes — `__init__.py` is empty.
