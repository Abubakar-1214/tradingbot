Each script is run directly as a standalone module (e.g. `python eval/eval_ppo.py`, `python eval/baselines.py`, `python eval/analyze_dreamer.py --checkpoint train/dreamer/dreamer_xauusd_final.pt --num_steps 1000`). They expect pre-trained checkpoints at `train/ppo_xauusd_latest.zip` or `train/ppo_xauusd_swing_latest`, macro data at `data/xauusd_1h_macro.csv`, and OHLC data at `data/xauusd_1h.csv`.
