Run each script directly as `python train/train_ppo.py`, `python train/train_dreamer.py`, `python train/train_god_mode.py`, `python train/train_ppo_aggressive.py`, or `python train/train_ultimate_150.py`; PPO scripts require `mp.set_start_method('spawn')` (already set) to avoid macOS fork issues. DreamerV3 scripts accept `--steps`, `--batch-size`, `--device {auto|cuda|mps|cpu}`, and `--resume <path>` flags. Data files must exist at `data/xauusd_1h.csv` (basic) or `data/xauusd_1h_macro.csv` (macro/God Mode/Ultimate variants).
