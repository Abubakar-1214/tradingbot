Each file is an independent `__main__` script with no shared base class; scripts split into two families. The PPO family (`train_ppo.py`, `train_ppo_aggressive.py`) uses stable-baselines3's `PPO` with a `SubprocVecEnv` of `XAUUSDTradingEnv` (or `XAUUSDTradingEnvAggressive`) instances, chunked learning via repeated `model.learn(..., reset_num_timesteps=False)` calls, and saves `.zip` checkpoints under `train/`. The DreamerV3 family (`train_dreamer.py`, `train_god_mode.py`, `train_ultimate_150.py`) defines a small local `TradingEnvironment` wrapper around raw `(X, r)` arrays, instantiates a `DreamerV3Agent` from `models.dreamer_agent`, runs a two-phase loop (prefill replay buffer with random actions, then alternating act/train), and saves `.pt` checkpoints under `train/dreamer*`. All scripts load features via `features.make_features` or specialized pipelines (`god_mode_features`, `ultimate_150_features`), split by `TRAIN_END_DATE` using `np.searchsorted` on the `time` column, and run a deterministic rollout evaluation on the held-out test slice after training. Dependency direction is strictly one-way: scripts → features pipeline → env/model; there are no cross-imports between training scripts.
