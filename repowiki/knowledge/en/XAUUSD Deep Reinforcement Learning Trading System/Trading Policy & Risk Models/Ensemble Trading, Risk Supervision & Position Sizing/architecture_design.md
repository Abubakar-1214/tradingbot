Three independent, single-responsibility modules under `models/` with no cross-imports between them:
- `ensemble.py` defines `EnsembleAgent`, which instantiates N copies of any conforming agent class (requiring `act`, optional `get_q_value`, `train`, `save`, `load`) with perturbed seeds/architectures, then aggregates votes via majority rule and computes disagreement entropy as an uncertainty signal.
- `risk_supervisor.py` defines `RiskSupervisor`, a pure-deterministic safety layer that inspects each proposed trade against configurable hard limits (daily loss, max drawdown, volatility/spread/event filters, trade-rate throttling) and returns `(approved, reason)` tuples; it also exposes `SafeTradingAgent`, a thin wrapper that calls the AI agent first and overrides to flat when rejected. State is tracked in instance attributes (`daily_pnl`, `peak_equity`, `consecutive_losses`, `halt_until`) and reset via `reset_daily` / `emergency_shutdown`.
- `position_sizing.py` implements three sizing strategies — `KellyPositionSizer` (fractional Kelly with dynamic win-prob estimation from a DreamerV3-style critic), `FixedFractionSizer`, and `ATRPositionSizer` — all exposing a uniform `compute_position_size(...)` interface so they are interchangeable at runtime.
The dependency direction is one-way: higher-level orchestration code would compose these three modules (ensemble → risk supervisor → position sizer); within this scope the files remain decoupled.
